The TeamSpeak App for Homey shows who is online on your TeamSpeak server and lets you automate on it.

Homey connects to the ServerQuery interface of your own or hosted TeamSpeak 3 server. You need the query login of the server, for example the serveradmin account, or a dedicated query account.

You can use the TeamSpeak App for Homey to:

- See who is online, per channel, with the "Online users" dashboard widget
- See at a glance who is away, has muted their microphone or sound, and how long everybody has been online
- Start a Flow when anyone, or one specific person, joins or leaves the server
- Start a Flow when the first person joins an empty server or the last person leaves
- Start a Flow when someone switches channels or when the number of online users changes
- Get notified when your server goes offline and when it comes back
- Check in Flows whether a person is online, whether anyone is online, or whether more than a number of people are online
- Send a message to the server chat or poke a user from a Flow
- Keep track of the number of online users, the average ping, packet loss and uptime in Insights

Joins and leaves are picked up instantly, the rest of the server status refreshes every 30 seconds by default.

The widget requires Homey v12.4.0 or newer.
